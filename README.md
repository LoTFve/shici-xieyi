# 诗词写意

输入一首古诗词，生成它的画面。

- **意象**：诗里写到的具体景物，决定画什么。比如月、山、江、舟、雪、松、钟、渔火，目前能识别 24 种。景物后面紧跟“绝、无、灭、歇、后”时视为没有，不画，比如“鸟飞绝”不画鸟。
- **意境**：整首诗的时辰、季节和情感，决定怎么画。时辰定天色，季节定山色，情感定饱和度、明暗、雾气、动画快慢和逐字显现的速度。

左侧面板会列出每一项的判断依据。

## 使用

用浏览器打开 `index.html`，没有依赖，也不用构建。可以选预置的诗，也可以自己粘贴，格式是第一行标题、第二行作者，后面是正文。

在网址后面加 `#诗名` 可以直接打开预置的诗，比如 `index.html#枫桥夜泊`。

## 已知局限

- 意境靠关键词计分，碰到用典、反语、比喻会判错。
- 景物的位置是固定的，不同的诗之间会有模板感。
