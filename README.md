# 诗词写意

输入一首古诗词，生成它的画面。

- **意象**：诗里写到的具体景物，决定画什么。比如月、山、江、舟、雪、松、钟、渔火，目前能识别 24 种。景物后面紧跟“绝、无、灭、歇、后”时视为没有，不画，比如“鸟飞绝”不画鸟。
- **意境**：整首诗的时辰、季节和情感，决定怎么画。时辰定天色，季节定山色，情感定饱和度、明暗、雾气、动画快慢和逐字显现的速度。

左侧面板会列出每一项的判断依据。

## 本体与大模型

- **本体**（`ontology.js`）：意象、时辰、季节、情感这些概念，以及它们之间的关系。比如枫蕴含秋，渔人需要舟，日不出现在夜里。规则和模型都只能在这些概念里选。
- **规则**：按本体里的字词匹配，同步出图，不联网也能用。
- **大模型**：后端把诗和本体概念发给大模型（默认 DeepSeek，任何 OpenAI 兼容接口都行），让它判断每个意象是实景、否定、比喻、借指、用典还是虚写，并给出时辰、季节、情感和原文证据。
- **融合**：模型给的证据必须能在原文里找到，找不到的判断丢弃，改用规则的结果。最后由本体补全依赖、推断缺失的时辰季节、去掉冲突项。

面板里每一项都标出来源：蓝底是模型，绿底是本体推断，红框是和规则判断不同的地方。鼠标悬停可以看到理由。

## 使用

不用模型：用浏览器直接打开 `index.html`，只用规则。

用模型：在项目根目录建 `.env`：

```
DS_KEY=你的key
DS_URL=https://api.deepseek.com
DS_MODEL=deepseek-chat
```

`DS_URL` 可以换成任何 OpenAI 兼容接口（比如 `https://api.openai.com/v1`），`DS_MODEL` 不填默认 `deepseek-chat`。然后运行：

```
npm install
npm start
```

打开 http://localhost:8000 。面板上的“大模型”勾选框可以关掉模型。模型结果按诗文缓存在浏览器 localStorage 里。`.env` 已在 `.gitignore` 里，不会被提交。

可以选预置的诗，也可以自己粘贴，格式是第一行标题、第二行作者，后面是正文。

在网址后面加 `#诗名` 可以直接打开预置的诗，比如 `index.html#枫桥夜泊`。

## 已知局限

- 不用模型时，意境靠关键词计分，碰到用典、反语、比喻会判错。
- 模型只能从本体里已有的概念中选，本体里没有的景物画不出来。
- 景物的位置是固定的，不同的诗之间会有模板感。
